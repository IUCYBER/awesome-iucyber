## 🏷️ Etiketler (Lejant)

Her kaynağın yanında aşağıdaki etiketler bulunur. Sayfada `Ctrl + F` ile etiket aratarak filtreleyebilirsin.

| Seviye | Tür | Dil | Ücret |
| ------ | --- | --- | ----- |
| `🟢 Başlangıç` | `📺 Video` | `🇹🇷 TR` | `🆓 Ücretsiz` |
| `🟡 Orta`      | `📚 Okuma` | `🇬🇧 EN` | `💰 Ücretli` |
| `🔴 İleri`     | `🧪 Lab`   |          | `🆓/💰 Kısmen` |
|                | `🎓 Kurs`  |          |  |
|                | `🛠️ Araç`  |          |  |

Ek olarak **⭐** işareti, kulübün özellikle önerdiği kaynakları gösterir.

## 🔎 Nasıl Aranır?

1. **Web sitesi (önerilen):** [iucyber.github.io/awesome-iucyber](https://iucyber.github.io/awesome-iucyber/) adresindeki arama kutusu tüm kaynaklarda anında arama yapar.
2. **GitHub içinde:** Repo sayfasında `/` tuşuna bas → `repo:IUCYBER/awesome-iucyber kelime` yaz.
3. **Sayfa içinde:** Bir kategori sayfasındayken `Ctrl + F` → `🟢 Başlangıç`, `🇹🇷 TR`, `🆓` gibi etiketleri arat.
