# 🛡️ IUCyber Kaynak Reposu

**Sıfırdan ileri seviyeye siber güvenlik kaynakları.** **IUCyber** (İstanbul Üniversitesi-Cerrahpaşa Siber Güvenlik Kulübü) üyeleriyle birlikte büyüyen kaynak kütüphanesi.

> [!TIP]
> Yukarıdaki **arama kutusunu** kullanarak tüm kaynaklarda arama yapabilirsin. Etiketlerle de arayabilirsin: `Başlangıç`, `TR`, `Ücretsiz`, `Lab`...

## 👋 Nereden başlamalıyım?

| Sen...                                                  | Buradan başla |
| ------------------------------------------------------- | ------------- |
| Siber güvenliğe **yeni** mi giriyorsun?                 | [🚀 Başlangıç Paketi](00-baslangic/README.md) |
| Temeli var, **bir alan seçmek** mi istiyorsun?          | [🗺️ Yol Haritaları](roadmaps/README.md) |
| Belirli bir konuda **kaynak** mı arıyorsun?             | Üstteki **📂 Kategoriler** sekmesi veya arama |
| Elindeki güzel bir kaynağı **paylaşmak** mı istiyorsun? | [🤝 Katkı Rehberi](CONTRIBUTING.md) |
